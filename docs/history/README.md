# 历史文档（归档）

本目录保存的是**开发过程中的规划与评审记录**，按当时的版本号与代码状态原样归档，不再是当前实现的说明。

当前实现请看：

- [`../DESIGN.md`](../DESIGN.md) — 架构与模块设计（随代码维护）
- [`../../README.md`](../../README.md) — 安装、使用、配置与限制
- [`../../CHANGELOG.md`](../../CHANGELOG.md) — 版本变更记录

| 文件 | 原用途 | 归档原因 |
|---|---|---|
| `PLAN-cmd-dialect.md` | `cmd.exe` 方言的 P0/P1 施工单（目标版本 0.2.0） | 已交付，计划内容与现状合并在 `DESIGN.md` §6 |
| `PLAN-confined-bash.md` | Windows 受限沙箱下 Git Bash 的处理（0.4.0 时代的编号） | 已交付，现行语义见 `DESIGN.md` §4 与 README「沙箱策略」 |
| `PLAN-minimal-mode.md` | 官方 `minimal` 预设的三种处理方式（0.5.0/0.5.1 时代的编号） | 已交付，现行语义见 `DESIGN.md` §5 |
| `REVIEW-cmd-dialect.md` | `cmd` 方言交付前的独立评审（B1–B10 / P1-1–P1-8） | 评审项已全部落地，结论保留作追溯 |

> 注意：这些文档里的版本号是重编号之前的旧编号（`0.4.x` / `0.5.x`），与现在的 `0.1.x` / `0.2.x` 不是同一套；对照表见 `CHANGELOG.md` 的「Version numbering」一节。文档中描述的设置行文案（如「终端工具」「受限沙箱时」「直接启动（不经沙箱）」）是 0.2.1 改版前的旧文案。
